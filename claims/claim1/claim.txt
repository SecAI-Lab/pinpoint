PinPoint Retrieval Effectiveness

This claim demonstrates that PinPoint improves the retrieval of known vulnerable
code over the BCSD backbone it is built on, and that the improvement does not
depend on which backbone that is. The packaged subset is run four times: each of
two backbones is evaluated standalone, using Stage 1 alone, which is
whole-function matching, and then as a PinPoint backbone, which adds the
block-stride and token-stride stages. All four runs are scored by the same
analysis code that produced the paper's table. Results are reported per inlining
type (Types I-IV) and overall, reproducing Table III. The gain concentrates on
Type II, where the compiler inlined the vulnerable function into a
non-vulnerable host, and is largest for SAFE, whose standalone Type II accuracy
is close to zero.

The BCSD backbones are used with their published weights, without fine-tuning.
BinShot is from: S. Ahn, S. Ahn, H. Koo, and Y. Paek, "Practical binary code
similarity detection with BERT-based transferable similarity learning," in
Proceedings of the 38th Annual Computer Security Applications Conference
(ACSAC '22), 2022. SAFE is from: L. Massarelli, G. A. Di Luna, F. Petroni,
L. Querzoni, and R. Baldoni, "SAFE: Self-attentive function embeddings for
binary similarity," in Detection of Intrusions and Malware, and Vulnerability
Assessment (DIMVA), 2019.
