Ethics

artmeta asks about the ethics of the data collection.

No human subjects:
- No data was collected from or about people. No participants, no surveys, no
  telemetry, and no personally identifying information.
- No institutional review was applicable and none was sought.

The inputs are public software:
- Every input is the source code of publicly released open-source software,
  obtained from the projects' own release channels and used under their
  licenses; license.txt lists them.
- The artifact redistributes neither that source nor the binaries built from
  it, only static-analysis output.

The vulnerabilities are already disclosed:
- All 73 CVEs were publicly disclosed and fixed upstream before this work began.
  This work discloses no new vulnerability and had no disclosure obligation.
- Binaries are analyzed, never executed. The artifact contains no exploit, no
  proof-of-concept input and no crash trigger.

Dual use:
- Locating a known vulnerability in a stripped binary is useful to whoever is
  looking. We judge the balance to favor publication:
- The vulnerabilities and their patches are already public. An attacker who
  wants to know whether a binary is unpatched has simpler routes, starting with
  the version string.
- What the paper adds is precision, not discovery. PinPoint answers which bytes
  of a function are the vulnerable ones, for a vulnerability the operator
  already knows about. That is the question a binary patcher must answer and the
  one an attacker least needs.
- The intended use is defensive: narrowing the window between disclosure and a
  deployed patch. See use.txt.
